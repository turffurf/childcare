# Licensed child care

A site for looking up licensed child care centres in a Canadian city. Toronto, Ontario is the published list.

Search by name, street, school, phone, language, or postal code. Narrow results by distance, area, program, vacancy, rating, operator, fee subsidy, and CWELCC. A short misspelling of a longer word still matches. A full postal code measures from that point; the first three characters measure from the nearest point in that area.

The map shows each centre, coloured by its highest published program rating, and can be limited to one area. Areas and programs list the centres in that group. Opening a centre shows the copied public record for that place.

The header shows the province and city. While only one of each is published, those names are labels. A menu appears when another province or city is added. The last city and colour theme are kept when the browser allows it. Sage is the theme used when nothing is stored.

The footer names the city, when the list was last updated, and the source. Vacancy text is that snapshot. Call the centre for a current opening.
